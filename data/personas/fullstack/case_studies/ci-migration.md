# Case study: CI/CD and infra migration

Client industry: SaaS
Year: 2025
Skills: GitHub Actions, Terraform, AWS

## Problem
The client in the SaaS sector needed a migration from Jenkins to GitHub Actions with IaC.

## What I did
I designed and built a migration from Jenkins to GitHub Actions with IaC using GitHub Actions, Terraform and AWS. I worked directly with the client's team, wrote documentation and handed over tests.

## Outcome
The project cut deploy time from 40 to 8 minutes.
