# Case study: Fitness mobile app

Client industry: fitness
Year: 2021
Skills: React Native, Expo, Firebase

## Problem
The client in the fitness sector needed a cross-platform workout tracker with offline sync.

## What I did
I designed and built a cross-platform workout tracker with offline sync using React Native, Expo and Firebase. I worked directly with the client's team, wrote documentation and handed over tests.

## Outcome
The project reached 4.7 stars with 10k installs.
