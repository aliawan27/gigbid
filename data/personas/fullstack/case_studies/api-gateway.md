# Case study: Payments API gateway

Client industry: fintech
Year: 2024
Skills: FastAPI, OAuth2, PostgreSQL, Docker

## Problem
The client in the fintech sector needed a partner API gateway with OAuth2 client credentials.

## What I did
I designed and built a partner API gateway with OAuth2 client credentials using FastAPI, OAuth2, PostgreSQL and Docker. I worked directly with the client's team, wrote documentation and handed over tests.

## Outcome
The project kept p95 latency under 120 ms.
