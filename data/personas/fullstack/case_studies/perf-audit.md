# Case study: Web performance overhaul

Client industry: e-commerce
Year: 2021
Skills: Core Web Vitals, Lighthouse, webpack

## Problem
The client in the e-commerce sector needed a performance audit and fix of a slow storefront.

## What I did
I designed and built a performance audit and fix of a slow storefront using Core Web Vitals, Lighthouse and webpack. I worked directly with the client's team, wrote documentation and handed over tests.

## Outcome
The project improved LCP from 4.1s to 1.6s.
