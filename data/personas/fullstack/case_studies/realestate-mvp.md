# Case study: Real-estate marketplace MVP

Client industry: real estate
Year: 2023
Skills: Next.js, Supabase, Tailwind CSS, Mapbox

## Problem
The client in the real estate sector needed a listing marketplace with map search.

## What I did
I designed and built a listing marketplace with map search using Next.js, Supabase, Tailwind CSS and Mapbox. I worked directly with the client's team, wrote documentation and handed over tests.

## Outcome
The project launched in 5 weeks and raised a pre-seed round.
