# Case study: Productivity Chrome extension

Client industry: productivity
Year: 2024
Skills: TypeScript, Chrome Extensions API

## Problem
The client in the productivity sector needed a tab and notes manager extension.

## What I did
I designed and built a tab and notes manager extension using TypeScript and Chrome Extensions API. I worked directly with the client's team, wrote documentation and handed over tests.

## Outcome
The project reached 15k weekly active users.
