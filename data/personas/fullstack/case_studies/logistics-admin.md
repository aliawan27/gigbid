# Case study: Logistics admin dashboard

Client industry: logistics
Year: 2025
Skills: Vue.js, Laravel, MySQL

## Problem
The client in the logistics sector needed an admin panel for dispatch and fleet tracking.

## What I did
I designed and built an admin panel for dispatch and fleet tracking using Vue.js, Laravel and MySQL. I worked directly with the client's team, wrote documentation and handed over tests.

## Outcome
The project replaced 6 spreadsheets used daily.
