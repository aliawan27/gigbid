# Case study: Headless CMS news site

Client industry: media
Year: 2025
Skills: Strapi, GraphQL, Next.js

## Problem
The client in the media sector needed a headless news site with incremental static regeneration.

## What I did
I designed and built a headless news site with incremental static regeneration using Strapi, GraphQL and Next.js. I worked directly with the client's team, wrote documentation and handed over tests.

## Outcome
The project cut page build time by 80%.
