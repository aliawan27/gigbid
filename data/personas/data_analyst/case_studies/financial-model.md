# Case study: Property financial model

Client industry: real estate
Year: 2024
Skills: Excel, financial modeling, Python

## Problem
The client in the real estate sector needed a 10-year cash-flow model for a property portfolio.

## What I did
I designed and built a 10-year cash-flow model for a property portfolio using Excel, financial modeling and Python. I worked directly with the client's team, wrote documentation and handed over tests.

## Outcome
The project supported a $4M refinancing decision.
