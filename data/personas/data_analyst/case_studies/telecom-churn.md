# Case study: Churn drivers analysis

Client industry: telecom
Year: 2022
Skills: Python, pandas, logistic regression

## Problem
The client in the telecom sector needed an analysis of churn drivers with an interpretable model.

## What I did
I designed and built an analysis of churn drivers with an interpretable model using Python, pandas and logistic regression. I worked directly with the client's team, wrote documentation and handed over tests.

## Outcome
The project targeted retention offers saved 3% of base.
