# Case study: Executive sales dashboard

Client industry: retail
Year: 2021
Skills: Power BI, DAX, SQL Server

## Problem
The client in the retail sector needed a sales dashboard used by 40 regional managers.

## What I did
I designed and built a sales dashboard used by 40 regional managers using Power BI, DAX and SQL Server. I worked directly with the client's team, wrote documentation and handed over tests.

## Outcome
The project replaced a 2-day monthly reporting process.
