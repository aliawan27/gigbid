# Case study: A/B testing programme

Client industry: fintech
Year: 2025
Skills: A/B testing, Python, statsmodels

## Problem
The client in the fintech sector needed an experimentation framework with power analysis.

## What I did
I designed and built an experimentation framework with power analysis using A/B testing, Python and statsmodels. I worked directly with the client's team, wrote documentation and handed over tests.

## Outcome
The project ran 22 experiments in one quarter.
