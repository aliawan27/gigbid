# Case study: Manufacturing ETL pipeline

Client industry: manufacturing
Year: 2025
Skills: Python, Airflow, PostgreSQL

## Problem
The client in the manufacturing sector needed ETL of machine sensor data into a reporting database.

## What I did
I designed and built ETL of machine sensor data into a reporting database using Python, Airflow and PostgreSQL. I worked directly with the client's team, wrote documentation and handed over tests.

## Outcome
The project made OEE reporting available hourly.
