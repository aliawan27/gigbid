# Case study: RAG customer-support assistant

Client industry: e-commerce
Year: 2022
Skills: LangChain, RAG, Pinecone, FastAPI, OpenAI API

## Problem
The client in the e-commerce sector needed a retrieval-augmented support bot over 12k help-centre articles.

## What I did
I designed and built a retrieval-augmented support bot over 12k help-centre articles using LangChain, RAG, Pinecone, FastAPI and OpenAI API. I worked directly with the client's team, wrote documentation and handed over tests.

## Outcome
The project deflected 34% of tickets.
