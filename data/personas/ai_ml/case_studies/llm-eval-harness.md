# Case study: LLM evaluation harness

Client industry: SaaS
Year: 2025
Skills: LLM evaluation, Python, pytest, LangSmith

## Problem
The client in the SaaS sector needed a regression-test harness for prompt and model changes.

## What I did
I designed and built a regression-test harness for prompt and model changes using LLM evaluation, Python, pytest and LangSmith. I worked directly with the client's team, wrote documentation and handed over tests.

## Outcome
The project caught 14 regressions before release.
