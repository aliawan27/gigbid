# Case study: Content recommender

Client industry: media
Year: 2022
Skills: recommender systems, PySpark, Python

## Problem

I designed and built an implicit-feedback recommender for 1.5M users using recommender systems, PySpark and Python. I worked directly with the client's team, wrote documentation and handed over tests.
