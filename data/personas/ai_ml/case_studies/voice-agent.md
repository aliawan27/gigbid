# Case study: Voice booking agent

Client industry: hospitality
Year: 2025
Skills: speech-to-text, Whisper, LangGraph, Twilio

## Problem
The client in the hospitality sector needed a phone agent that books restaurant tables.

## What I did
I designed and built a phone agent that books restaurant tables using speech-to-text, Whisper, LangGraph and Twilio. I worked directly with the client's team, wrote documentation and handed over tests.

## Outcome
The project handled 61% of calls end to end.
